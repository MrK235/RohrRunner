# Sicherheitsmeldungen

Bitte veröffentliche Zugangsdaten, personenbezogene Daten oder vertrauliche Projektdateien nicht in einem öffentlichen GitHub-Issue.

Wenn GitHub für dieses Repository die private Meldung einer Sicherheitslücke anbietet, verwende die Funktion **Report a vulnerability** auf der Security-Seite des Repositories. Falls sie nicht verfügbar ist, kontaktiere den Repository-Verantwortlichen direkt und privat über GitHub. Für reine Bedien- oder Rechenfehler bitte `BUGS.md` und das öffentliche Issue-Formular verwenden.

Eine `.rohrrunner`-Projektdatei kann den eingebetteten PDF-Grundriss enthalten. Vor dem Teilen bitte Dateiinhalt und Metadaten prüfen.
